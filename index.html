Физическое явление

Интерференция возникает, когда когерентные световые волны приходят в одну точку экрана с разной фазой. При совпадении фаз волны усиливают друг друга, поэтому появляется светлая полоса. При противоположных фазах волны ослабляют друг друга, и возникает тёмная полоса.

Длина волны λ, расстояние между щелями d и расстояние до экрана L определяют расстояние между полосами. Фазовый сдвиг φ смещает всю интерференционную картину.

Формулы

  • δ = d * y / L — разность хода для точки экрана с координатой y.
  • Δφ = 2π * δ / λ + φ — разность фаз двух волн.
  • I(y) = I0 * cos²(Δφ / 2) — интенсивность для двух щелей.
  • λ переводится из нм в м, d — из мм в м.
  • Для трёх щелей модель складывает амплитуды волн: A = Σ cos(phase_i), I = A².
  • Для второго уровня используется простая маска: I_total = I_1(y) * I_2(y).
